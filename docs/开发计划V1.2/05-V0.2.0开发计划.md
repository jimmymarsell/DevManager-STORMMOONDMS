## 一、V0.2.0 目标概述

基于 V0.1.0 已完成的核心功能，V0.2.0 聚焦三大方向：

1. **质量加固**：补充单元测试、完善异常处理、代码注释
2. **功能增强**：版本引用模式优化（支持复制到 versions 目录）、多版本批量操作
3. **体验优化**：命令补全、表格化输出、配置校验修复

---

## 四、P6：功能增强（2 天）

### P6-A：版本引用模式优化

| 编号 | 任务 | 产出文件 | 验收标准 |
|:---|:---|:---|:---|
| P6-01 | add 命令增加 --copy 参数 | cmd/jdk.go, cmd/maven.go | 指定 --copy 时将版本目录复制到 versions/ 下 |
| P6-02 | 实现 CopyVersionToVersions() | pkg/util.go | 复制目录到 versions/jdk/version/ 下 |
| P6-03 | use 命令优先使用本地拷贝 | internal/service/jdk_service.go | 本地拷贝存在时软链接指向本地拷贝 |

> **设计说明**：当前 add 命令是引用模式（软链接指向原始路径），V0.2.0 增加可选的 `--copy` 模式，将版本文件复制到 `versions/` 目录下集中管理。默认仍为引用模式。
