### 3.2 P1-A：模型层结构体定义

```go
// config.json 对应的 Go 结构体
type Config struct {

type EnvConfig struct {
    Current     string                 `json:"current"`

type VersionInfo struct {
    Version string `json:"version"`

### 3.3 P1-C：软链接模块关键实现要点

#### Windows Junction Point 创建伪代码

```
函数 CreateSymlink(linkPath, targetPath):
    如果 Windows:
        先尝试 os.Symlink(targetPath, linkPath) 创建 Junction Point
        如果失败:
            尝试 os.Symlink(targetPath, linkPath) 创建 Symbolic Link（需开发者模式）
            如果再失败:
                返回错误，提示权限不足或杀毒软件拦截
    如果 Linux/macOS:
        直接调用 os.Symlink(targetPath, linkPath)
```

#### 关键注意事项

1. Windows Junction Point 使用 `os.Symlink()` 时，Go 会根据目标是否存在自动选择 Junction 或 Symlink
2. 删除软链接需使用 `os.Remove()`，不能用 `os.RemoveAll()`（避免删除目标目录内容）
3. 检测软链接使用 `os.Readlink()`
4. 所有路径操作必须使用 `filepath` 标准库，禁止硬编码分隔符

### 3.4 P1-E：环境变量配置模块关键实现要点

#### Windows 注册表操作伪代码

```
函数 SetupWindowsEnv(installDir):
    // 1. 设置 STORMMOON_HOME
    写入注册表 HKEY_CURRENT_USER\Environment "STORMMOON_HOME" = installDir

    // 2. 设置 JAVA_HOME
    写入注册表 HKEY_CURRENT_USER\Environment "JAVA_HOME" = installDir + "\symlinks\jdk"

    // 3. 设置 MAVEN_HOME
    写入注册表 HKEY_CURRENT_USER\Environment "MAVEN_HOME" = installDir + "\symlinks\maven"

    // 4. 追加 PATH
    读取当前 PATH
    追加 "%STORMMOON_HOME%;%JAVA_HOME%\bin;%MAVEN_HOME%\bin"
    写入注册表

    // 5. 广播 WM_SETTINGCHANGE
    调用系统 API 广播环境变量变更通知
```

#### Linux/macOS Shell 配置伪代码

```
函数 SetupUnixEnv(installDir):
    // 1. 检测 Shell 类型
    shell = DetectShell()

    // 2. 确定配置文件路径
    根据shell类型选择 .bashrc / .zshrc / config.fish

    // 3. 检测是否已存在 DevManager 配置
    如果已存在:
        跳过写入
        返回

    // 4. 追加 export 语句
    追加以下内容到配置文件末尾:
        export STORMMOON_HOME=installDir
        export JAVA_HOME=installDir/symlinks/jdk
        export MAVEN_HOME=installDir/symlinks/maven
        export PATH=$STORMMOON_HOME:$JAVA_HOME/bin:$MAVEN_HOME/bin:$PATH

    // 5. 输出提示：请重新打开终端或执行 source 命令
```

### 3.5 P2-A/B：版本自动识别关键实现

#### JDK 版本识别伪代码

```
函数 DetectJdkVersion(jdkPath):
    // 1. 校验路径
    如果 Windows:
        javaExe = jdkPath + "/bin/java.exe"
    否则:
        javaExe = jdkPath + "/bin/java"

    如果 javaExe 不存在:
        返回错误 "JDK 路径不合法"

    // 2. 执行版本命令
    执行 javaExe + " -version"
    解析输出提取版本号（如 1.8.0_391、17.0.9）

    // 3. 解析失败允许手动指定
    如果解析失败:
        返回提示 "无法自动识别版本号，请手动指定 --version"
```

#### Maven 版本识别伪代码

```
函数 DetectMavenVersion(mavenPath):
    // 1. 校验路径
    如果 Windows:
        mvnExe = mavenPath + "/bin/mvn.exe"
    否则:
        mvnExe = mavenPath + "/bin/mvn"

    如果 mvnExe 不存在:
        返回错误 "Maven 路径不合法"

    // 2. 执行版本命令
    执行 mvnExe + " -v"
    解析输出提取版本号（如 3.6.3、3.8.8）

    // 3. 解析失败允许手动指定
    如果解析失败:
        返回提示 "无法自动识别版本号，请手动指定 --version"
```

### 3.6 P3：命令层 CLI 设计

#### 命令结构

```
stormmoondms                          # 根命令，显示帮助信息
stormmoondms version                  # 显示版本号
stormmoondms env setup                # 手动触发环境变量配置
stormmoondms jdk add --path <path>    # 添加 JDK 版本
stormmoondms jdk add --path <path> --version <ver>  # 手动指定版本号
stormmoondms jdk list                 # 列出所有 JDK 版本
stormmoondms jdk use <version>        # 切换 JDK 版本
stormmoondms jdk uninstall <version>  # 卸载 JDK 版本
stormmoondms maven add --path <path>  # 添加 Maven 版本
stormmoondms maven add --path <path> --version <ver> # 手动指定版本号
stormmoondms maven list               # 列出所有 Maven 版本
stormmoondms maven use <version>      # 切换 Maven 版本
stormmoondms maven uninstall <version> # 卸载 Maven 版本
```

#### 输出示例

```

* 17.0.9          ← 当前使用版本

# jdk use 1.8.0_391 输出示例

  请重新打开终端窗口使环境变量生效

# jdk add --path D:\Java\jdk-17 输出示例

## 四、风险项开发注意事项

| 风险编号 | 风险描述                   | 开发注意事项                                                    |
| :------- | :------------------------- | :-------------------------------------------------------------- |
| R1       | Windows 软链接权限不足     | 先 Junction Point 后 Symbolic Link 降级，两层失败均给出明确提示 |
| R1.1     | Windows 开发者模式未开启   | 仅在 Symbolic Link 降级场景出现，输出开启指引                   |
| R2       | 杀毒软件拦截软链接         | 软链接创建结果检测，失败时提示排查安全软件                      |
| R3       | 终端缓存环境变量不立即生效 | 每次切换成功强制提示「重启终端生效」                            |
| R4       | 配置文件人为手动篡改损坏   | 加载时 JSON 格式校验，损坏自动备份并重置                        |
| R5       | 跨平台路径分隔符不统一     | 全程使用 filepath 标准库，禁止硬编码 `\` 或 `/`                 |
| R6       | 版本目录被手动删除         | list/use 时校验路径有效性，无效路径标灰警告                     |
| R7       | 编译后体积过大             | 严格控制第三方库数量，编译 -ldflags "-s -w"                     |
| R8       | 环境变量自动配置失败       | 配置失败不阻塞启动，仅输出警告，提供手动命令触发                |
| R9       | Shell 类型检测错误         | 默认 .bashrc，输出提示告知配置到了哪个文件                      |
