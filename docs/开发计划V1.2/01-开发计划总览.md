## 一、项目概述

DevManager(STORMMOON) 是一款轻量级跨平台开发环境版本管理器，支持 JDK、Maven 版本的添加、切换、列表展示与卸载，采用「固定环境变量 + 全局统一软链接」核心方案，用户仅需配置一次环境变量，后续切换版本全自动完成。

### 1.1 项目目标

1. V0.1.0 完成 JDK 和 Maven 两大运行环境版本管理
2. 支持 Windows / Linux / macOS 三平台
3. 零管理员权限运行
4. 单文件可执行、无外部依赖
5. 架构可插拔，后续扩展 Python / Node 无需改核心代码

### 1.2 技术栈

| 技术分类 | 选型 |
|:---|:---|
| 开发语言 | Go 1.26 |
| CLI 框架 | cobra |
| 颜色输出 | fatih/color |
| 配置文件 | JSON（标准库） |
| 文件操作 | os、filepath 原生库 |
| 软链接 | 系统原生 API |
| 环境变量（Windows） | golang.org/x/sys/windows/registry |
| 环境变量（Linux/macOS） | os、bufio 标准库 |
| 编译方式 | 静态编译、无依赖 |

## 二、开发阶段划分

项目 V0.1.0 开发划分为 **5 个阶段**，严格遵循自底向上、分层推进原则：

| 阶段 | 名称 | 核心内容 | 预估工时 |
|:---|:---|:---|:---|
| P0 | 项目初始化与基础设施 | Go工程初始化、依赖引入、目录结构搭建 | 0.5 天 |
| P1 | 核心通用层开发 | 配置管理、软链接模块、环境检测、环境变量配置、模型定义、公共工具 | 3 天 |
| P2 | 业务服务层开发 | JDK Service、Maven Service | 2 天 |
| P3 | 命令层开发与集成 | 根命令、JDK 子命令、Maven 子命令、环境变量自动配置交互 | 1.5 天 |
| P4 | 跨平台测试与修复 | Windows/Linux/macOS 联调、异常处理完善、打包编译 | 2 天 |

**总预估工时**：9 天

## 三、开发优先级原则

1. **底层优先**：先完成 config、model、symlink 等核心层，再开发业务层和命令层
2. **高风控先做**：软链接跨平台实现、环境变量注册表操作是高风控模块，优先开发验证
3. **可独立验证**：每个模块开发完即可独立测试，不依赖后续模块
4. **核心链路优先**：先打通「添加版本 → 切换版本 → 验证生效」的核心链路

---

## 四、关键里程碑

| 里程碑 | 验收标准 |
|:---|:---|
| M1：核心层就绪 | config 读写正常、symlink 创建/删除/检测跨平台通过、model 定义完整 |
| M2：业务层就绪 | JDK add/list/use/uninstall 全流程通过、Maven 同理 |
| M3：命令层就绪 | CLI 命令全部可用、交互提示完整、环境变量自动配置可用 |
| M4：发布就绪 | 全平台编译通过、异常处理覆盖完整、产物体积 < 10MB |
